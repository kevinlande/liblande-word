# LibLande for Word: sign-in page

The Google sign-in page for LibLande's Word add-in. It lives here, not with
LibLande at kevinlande.github.io/liblande/, because the LibLande app on a
Mac (a Safari web app) opens every page under /liblande/ itself, which
took Google's sign-in away from Word's window.

Built from bibdesk-web/pages/word/signin.html in the LibLande project.
